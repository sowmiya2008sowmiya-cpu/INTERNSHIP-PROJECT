Student Performance Prediction

About the Project

This is an interactive machine learning web application designed to instantly predict a student's academic performance level based on various inputs.


The System Analyzes

  • Study Habits & Attendance: Study hours per week, attendance percentage, and previous exam scores.
  • Subject Performance: Individual scores in Math, Science, and English.
  • Socio-Economic Factors: Parental education, internet access, extracurricular activities, socio-economic status, and school type.
